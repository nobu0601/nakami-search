# なかみ検索

フォルダを登録すると、その中のファイルを **ファイル名と中身の両方** から検索できる Windows アプリです。

## できること

- **中身の検索**: テキスト・CSV・JSON・Markdown・コード・PDF・Word(.docx)・PowerPoint(.pptx)・Excel(.xlsx/.xlsm/.xls)
- **文字認識**: 画像（png・jpg・jpeg・bmp・tiff）とスキャンした PDF の文字も読み取る（日本語・英語。バックグラウンドで処理）
- **ファイル名の検索**: 動画（mp4 など）を含むすべてのファイル
- **絞り込みと並べ替え**: 更新日（今日・7日・30日・1年）、フォルダ、種類。一致の多い順・新しい順・古い順・名前順・サイズ順
- **検索履歴とお気に入り**: 検索欄をクリックすると最近の検索と ★ を付けた検索が出る
- **呼び出しキー**: どの画面からでも `Ctrl + Shift + Space`（設定で変更可）。閉じてもタスクトレイに常駐
- **変更の自動反映**: ファイルの追加・変更・削除をすぐ反映。アプリを閉じていた間の変更も起動時に取り込む
- **検索しないものの設定**: フォルダ名・ファイル名（`*` 使用可）と拡張子を設定画面で指定
- **自動アップデート**: 新しい版が出ると自動でダウンロードし、次に終了したときに入れ替わる
- 検索結果から「開く」で元のアプリで開く、「フォルダで表示」でエクスプローラーを開く
- 全角・半角を区別しない。Shift_JIS のテキストも読める。`"見積 書"` でフレーズ、`-下書き` で除外、正規表現にも対応

ファイルの中身はパソコンの外には送信されません。索引と設定は `%APPDATA%\なかみ検索\` に保存されます。

## インストール

Releases（または Actions の成果物）から `nakami-search-setup-x.y.z.exe` をダウンロードして実行します。
署名していないため、初回に「Windows によって PC が保護されました」と出たら「詳細情報」→「実行」を押してください。

## 開発

```bash
npm install
npm test        # 検索・索引のテスト
npm start       # アプリを起動
npm run dist:win  # Windows インストーラーを作成（Windows 上で実行）
```

`main` に push すると、GitHub Actions がインストーラーを作り、`package.json` の version 名の Release に添付します。新しい版を出すときは version を上げてください。

## 構成

| ファイル | 役割 |
| --- | --- |
| `src/main.js` | ウィンドウ、フォルダ監視、画面とのやり取り |
| `src/indexer.js` | 索引の作成・更新・保存 |
| `src/extract.js` | 各形式のファイルから文字を取り出す |
| `src/search.js` | 検索式の解釈・絞り込み・並べ替え・一致箇所の計算 |
| `src/ocr.js` | 画像の文字認識（tesseract.js、言語データ同梱） |
| `src/settings.js` | 設定・検索履歴・お気に入りの保存 |
| `src/renderer/` | 画面 |
